# Ryan — Portfólio

Abra `index.html` no navegador para ver o portfólio.

## Como adicionar programas à loja

No `index.html`, procure pela seção `id="loja"`. Copie um dos links com a classe `project` e edite o título (`h3`), o texto de apoio (`p`), o símbolo e o endereço em `href`.

## GitHub Pages

Envie o `index.html` para a raiz da branch `main`. No repositório, abra **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e `/(root)` e clique em **Save**.
